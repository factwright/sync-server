# Factwright’s sync server, ready to deploy

Factwright’s sync server, built and ready to run in your own Cloudflare account for free, arrives here with Factwright’s next release, with a Deploy to Cloudflare button and the steps around it.

Until then, the server’s source and how to run your own are in [factwright/factwright](https://github.com/factwright/factwright/tree/main/apps/server#running-your-own).
